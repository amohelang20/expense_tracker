# Expense Tracker

A command-line expense tracker built with Python. Track your spending, filter by category, and view summaries.

## How to Run

```bash
python3 expense_tracker.py
```

## Features

- Add expenses with date, category, description, and amount
- View all expenses in a formatted table
- Filter expenses by category
- View spending summaries with category breakdown
- Data persists between sessions (saved to CSV)
